# 角色与岗位分析

## 目标与范围

围绕一个明确的人员、岗位或工作角色，判断岗位要求与实际角色承担之间的关系。此 Skill 可处理岗位适配、职责匹配、责任边界、角色负荷与岗位变化影响；所有任务均使用本 Skill 的同一输出结构。

不要把人物画像、人格类型或职位名称直接等同于角色结论；不要将团队整体角色生态、项目风险或管理干预方案替代本分析。

## 输入

调用方按问题范围提供：

- `person_profile`：与工作经历、行为、沟通和协作有关的可观察材料；
- `person_model`：已有职业画像，作为背景解释而非事实替代；
- `formal_position`：正式岗位、职责范围、所属单元和汇报关系；
- `target_role`：明确的目标岗位或角色要求；未提供时不得自行设定；
- `relationship_snapshot`：与目标人员或职责交接直接相关的协作关系；
- `team_context`：仅在问题涉及职责承载或协作影响时提供的团队范围信息。

缺少岗位要求、正式职责或足以支持判断的工作材料时，说明信息缺口，不用常识补齐。

## 工作流程

1. 先调用 `resolve_authorized_person(task_id, person_name)` 取得当前 Task 已授权的人员、组织、快照和团队标识；不得猜测标识，也不得通过 shell 或运行目录查找业务资料。
2. 将请求归入一个或多个 `analysis_focus`：`岗位适配`、`职责匹配`、`边界与重叠`、`角色负荷`、`岗位变化影响`；不因标题自行扩大范围。
3. 分别整理岗位或角色的核心责任、协作接口和判断要求；当事人的实际职责、可观察行为和协作贡献；以及两者的匹配、错位、未覆盖与支持条件。
4. 区分证据层级：正式职责、直接工作记录属于事实；重复出现的他人描述或互动模式属于观察；由多项材料得出的判断属于推断。
5. 判断职责匹配、边界清晰度、重叠或缺口、负荷与责任集中，以及直接协作和责任衔接可能受到的影响。
6. 按需阅读 [角色匹配与工作设计参考](references/role-fit-and-work-design.md)，用理论解释工作材料；理论不是证据，也不构成心理诊断。
7. 形成带有适用条件的结论。无法支持判断时，使用 `insufficient_information`，并说明缺少什么及其影响。
8. 按下方 Markdown 输出契约生成完整报告，写入当前任务目录的 `result.md`，再调用任务提交动作。

## Markdown 输出契约

`result.md` 是本 Worker 的唯一正式结果。直接写完整 Markdown 报告，不生成其他格式的结果文件。

### 固定核心章节

每份报告必须包含以下章节：

```markdown
# {分析对象}：{分析主题}

## 分析范围

## 结论摘要

## 关键判断

## 详细分析

## 协作影响

## 风险与成立条件

## 依据

## 信息缺口

## 置信度
```

各章节按以下规则编写：

- **分析范围**：说明分析对象、当前或目标岗位、请求关注的问题，以及实际使用的业务材料范围。
- **结论摘要**：用一至三段直接回答原始问题，并说明结论成立的主要条件；信息不足时明确写出“信息不足，无法形成稳定判断”。
- **关键判断**：使用 Markdown 表格，列为“分析维度、判断、主要依据、影响或条件、置信度”。只列与当前问题有关的判断。
- **详细分析**：按任务需要选择“岗位适配”“职责匹配”“边界与重叠”“角色负荷”“岗位变化影响”中的一个或多个三级标题，不输出与任务无关的空模块。
- **协作影响**：说明当前角色承担对责任衔接、信息传递、决策或跨角色协作的直接影响；确实不涉及协作时写明“不在本次分析范围内”。
- **风险与成立条件**：区分已经出现的风险、可能发生的风险，以及结论赖以成立的条件。
- **依据**：使用 Markdown 表格，逐条列出“编号、类型、内容、支持的判断、来源说明”。类型只能是“事实”“观察”或“推断”，每条依据必须能对应到一项判断。
- **信息缺口**：列出缺失信息、它影响了哪项判断，以及补充后可以验证什么；无缺口时明确写“未发现影响主要结论的信息缺口”。
- **置信度**：使用“高”“中”“低”并说明原因，不使用没有计算依据的精确百分比。

### 表达要求

- 标题直接描述分析对象和主题，不追加数据源、系统名称、授权状态或内部说明。
- 先给结论，再展开依据；不写任务执行过程、工具调用过程或文件操作过程。
- 不输出任务 ID、房间号、内部人员 ID、组织快照 ID、工具名称、存储名称或授权流程。
- 不把人物画像标签直接当作岗位判断；所有判断必须回到可观察材料和岗位要求。
- 不为追求篇幅重复同一结论，也不因资料不足而编造经历、关系或岗位要求。
