# 协作关系边口径

关系边应描述工作机制而非私人评价。每条边表示一个无序成员对；`member_a` 和 `member_b` 只用于稳定标识，不表示方向或权力顺序。

- 执行依赖：一方的交付是另一方继续工作的前提。
- 信息转接：一方承担信息收集、转发或解释。
- 复核/审批：一方对另一方结果有质量或决策把关作用。
- 资源协调：一方控制或连接另一方所需资源。
- 竞争与互补：双方共享目标/资源，同时存在互补或竞争张力。

`valence` 表示当前关系整体倾向：`positive`、`neutral` 或 `negative`。复杂关系可使用 `neutral`，再在综合描述中写清互补和张力。

`salience` 1-5 以当前协作频率、依赖程度、不可替代性和对团队运行的影响判断。没有明确依据时，宁可不生成边。

`summary` 合并说明双方如何协作、彼此如何影响，不拆写两个方向，也不重复正式岗位说明。`risk` 只保留最主要的协作风险。证据材料另存为关系 Note，当前关系边不复制证据摘要。
